# WEB-A11Y-001 — Accessibility & Keyboard UX Hardening

## Status

PREPARED / BUILD + QA ONLY / NOT MERGED / NOT DEPLOYED

## Purpose

Strengthen baseline accessibility of the ISTRIADE corporate website without changing the normal visual design or product-commercial boundaries.

## Changes

- Makes the existing `Skip to content` link target a programmatically focusable `<main>` element.
- Adds a dedicated accessibility stylesheet loaded after the primary visual stylesheet.
- Adds a high-visibility `:focus-visible` treatment for links, controls, summaries and tabindex targets.
- Preserves the skip-link treatment with a distinct focus state.
- Adds minimum 44px touch/keyboard target height for mobile-menu links and the menu summary.
- Honors `prefers-reduced-motion: reduce` by disabling smooth scrolling and minimizing animation/transition motion.
- Prevents the product-card hover translation when reduced motion is requested.
- Adds a `forced-colors` focus treatment for high-contrast environments.
- Adds `scripts/accessibility-guard.mjs` and runs it as part of `npm run check`.

## Automated invariants

The accessibility guard verifies that:

- document language remains `en`;
- the skip link points to `#main-content`;
- the main content target remains programmatically focusable;
- keyboard focus styles remain present;
- reduced-motion support remains present;
- forced-colors focus support remains present;
- mobile navigation retains 44px minimum targets;
- primary and mobile navigation labels remain present;
- the brand home link retains an accessible label.

## Boundaries preserved

- no product content changes;
- no pricing, checkout, payment or fulfillment changes;
- no corporate policy changes;
- no product repository changes;
- no new marketing claims;
- no Cloudflare production deployment authorized.
